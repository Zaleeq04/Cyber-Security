## Purpose

The purpose of this logbook is to demonstrate practical cybersecurity knowledge and hands-on experience gained through laboratory exercises and reflective work.

The exercises show the application of cybersecurity concepts in both Windows and Linux environments, alongside practical cryptographic and access-control techniques.


This repository contains coursework and practical lab documentation completed for educational purposes. Any commands, configurations, or security techniques are intended for authorised laboratory environments only.
